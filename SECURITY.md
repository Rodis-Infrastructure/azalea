# Security

## Reporting a vulnerability

Report privately through [GitHub Security Advisories](https://github.com/Rodis-Infrastructure/azalea-new/security/advisories/new) if enabled; otherwise contact the maintainer on [GitHub](https://github.com/archasion) and ask for a private channel. Never post exploit details or credentials in a public issue.

Include the affected version or commit, impact, and a minimal reproduction, and allow time to investigate before public disclosure. There is no published response-time SLA or version support window; report against the latest source.
