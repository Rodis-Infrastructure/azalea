# Security

## Reporting a vulnerability

If private vulnerability reporting is enabled, submit a report through [GitHub Security Advisories](https://github.com/Rodis-Infrastructure/azalea-new/security/advisories/new). Otherwise, contact the maintainer through [GitHub](https://github.com/archasion) and request a private channel. Do not post exploit details or credentials in a public issue.

The repository does not publish a response-time SLA. Include the affected version or commit, impact, and a minimal reproduction, and allow the maintainer time to investigate before public disclosure.

## Supported versions

No formal version support window is published. Report vulnerabilities against the latest available source or release; fixes and backports are determined by the maintainer.
